امروز چی شد؟ — نسخه دو حوزه خبری و ۱۰ هشتگ (۱۴۰۵/۰۸/۱۵)

فایل‌های داخل بسته را در همان مسیرهای مخزن GitHub جایگزین کنید:
  news_rules.py
  main.py
  config.py
  bale.py
  .github/workflows/publish.yml

**هیچ‌یک از فایل‌های feeds.py ،state.py و state.json را پاک یا جایگزین نکنید.**
متغیرهای Secret/Variable در GitHub و تنظیمات cron-job.org نیز بدون تغییر بمانند.

حوزه‌های مجاز خبر: اقتصاد و بازار؛ سیاست، جنگ و تحولات مهم بین‌المللی.
فقط هشتگ‌های مجاز:
  #اقتصاد #دلار #طلا #بورس #بانک #مسکن #خودرو #سیاست #جنگ #جهان
حداکثر ۲ هشتگ مرتبط در هر خبر؛ هیچ هشتگ دیگری چاپ نمی‌شود.
خبرهای آشکارا کم‌اهمیت یا مراسمی حذف می‌شوند. شرط روزانه یا فاصله اجباری وجود ندارد.
هر اجرای workflow حداکثر یک خبر جدیدِ مهم منتشر می‌کند؛ زمان‌بندی خارجی ۵ دقیقه‌ای تغییری نکرده است.
انتشار عکس، لینک منبع، جلوگیری از تکرار و آخرین خط @emroozchishod محفوظ است.

تست اولیه:
  GitHub → Actions → Publish one news item → Run workflow
برای بررسی بدون ارسال، در محیطی که feeds.py و state.py وجود دارند:
  python main.py --preview
